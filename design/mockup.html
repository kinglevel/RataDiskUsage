RataDiskUsage

A working mockup of the terminal app. It combines diskonaut's navigation, darya's file browser, diskbloom's file types, and excise's layout and motion on one screen.

Sample data, about 170G. Nothing on your disk is read or deleted. Click the terminal to use the keyboard

Press r to replay the scan. Click a tile or a row to select it, and click it again to open it. Motion follows your system's reduced-motion setting.

Where each part comes from

diskonaut

Navigation

Arrow keys or hjkl move between tiles by position. Enter opens the selected folder, Esc returns to the parent, and Backspace asks before deleting. Entries too small to draw are grouped into one hatched tile.

Rust · tui 0.11 · MIT · last release 2020

darya

File browser

A tree with one row per entry: share bar, percentage and size. Right expands a folder in place and Left collapses it. Details of the selected entry sit in their own panel.

Rust · ratatui 0.30 · GPL-3.0

diskbloom

File types

Each extension gets a hue, ranked by total size and stepped by the golden angle (137.5°) so the largest types sit far apart. Folders take the colour of their largest type, and bigger shares are brighter. Folder tiles show their contents as a nested mosaic.

Go · Bubble Tea · Apache-2.0

excise

Layout and motion

A header band with a status chip, titled panes, an inspector for the selected item, and key hints on the last line. Tiles glide to new positions, the map zooms on drill in and out, a sheen crosses the selected tile once, and deleted tiles dissolve.

Rust · ratatui 0.30 + tachyonfx · MIT

How the parts were joined

  • The map and the file list share one selection. Moving in either pane moves the highlight in the other.
  • The map shows the current folder two levels deep. The file list can expand deeper, and a row selected there is outlined inside its parent tile.
  • Small entries cannot be selected on the map, as in diskonaut. They stay reachable in the file list.
  • Tiles are filled like excise's, but coloured by file type like diskbloom's. excise colours tiles by size alone.
  • The type legend covers the current folder and marks the type of the selected entry.

All but the dissolve are the values in excise's animation.rs. excise redraws every 33 ms while something moves and sleeps otherwise.

Keys

KeyAction
arrows / hjklMove between tiles, or between rows in the file list
EnterOpen the selected folder
EscGo up to the parent folder
TabSwitch between the map and the file list
→ / ←Expand or collapse a folder in the file list
Bksp or dDelete, after a y/n confirmation
rRescan the current folder
?Show the key list

Left out of the mockup

  • Filtering with / (excise, darya).
  • Zoom with + - 0, which hides the largest entries so small ones grow (diskonaut, excise).
  • Sort modes and switching between bytes and percentages (darya).
  • Exporting and importing a scan (darya, excise).
  • Themes (excise) and a Trash option next to permanent delete (diskbloom).
